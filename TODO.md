# Delivery outcomes

## Polished monochrome birthday experience
- Build a React website for a friend that feels black and white, bright, happy, subtle, clean, pretty, lively, wonderful, and emotionally moving.
- Keep the experience responsive so the visual language holds across mobile, tablet, and desktop.
- Use readable typography, accessible contrast, and gentle motion that adds warmth without disrupting the clean aesthetic.

## Welcome portrait and message
- The welcome page features her portrait.
- The welcome includes the title “A Little More Light” and a beautiful heartfelt caption.
- Include a graceful fallback state so the layout remains beautiful before the owner adds the welcome photo.

## Nine-photo keepsake gallery
- Present exactly nine photo moments in a clean, lively black-and-white composition.
- Label the photo file references as photo 01 through photo 09.
- Give every photo a dedicated caption and a description of the picture.
- Make each picture clickable and open it in an elegant enlarged viewing experience.
- Keep the gallery keyboard-friendly with usable focus states and Escape-to-close lightbox behavior.

## Future photo replacement
- Include a clearly organized local photos folder where the owner can later add or replace matching image files without changing the gallery structure.
- Document the expected filenames and the welcome portrait filename in the photo folder.
