# Your photos live here

Add the images for the birthday keepsake to this folder using these exact filenames:

- `welcome.jpeg` — the portrait shown as the illuminated welcome background
- `photo 01.jpeg` through `photo 09.jpeg` — the nine gallery moments

JPEG, JPG, PNG, and WEBP files all work. The code currently points to the `.jpeg` filenames above. The page includes a graceful placeholder until a matching image is present, so you can preview the whole experience before adding the photos.
